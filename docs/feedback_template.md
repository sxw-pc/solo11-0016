## 维护者排查建议

1. 先确认版本、Python 版本、操作系统与执行目录。
2. 用 `python -m archive_extractor.cli status <task_id>` 获取任务状态与计数。
3. 用 `python -m archive_extractor.cli errors <task_id> errors.csv` 导出错误清单。
4. 用 `python -m archive_extractor.cli trace <result_id>` 获取字段级溯源。
5. 性能问题附上文件规模、并发数、磁盘类型与是否启用实时杀毒扫描。
6. 规则问题附最小可复现 YAML 与合成 HTML 片段。
